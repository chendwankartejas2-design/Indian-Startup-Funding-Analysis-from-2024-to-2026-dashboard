# 🇮🇳 Indian Startup Funding Analysis | Power BI Dashboard

## 📌 Project Overview
This project analyzes Indian startup funding data using Microsoft Power BI. The dashboard provides insights into funding trends, startup industries, investment rounds, and investor activity to better understand the Indian startup ecosystem.

## 🎯 Objectives
- Analyze startup funding trends over different years.
- Identify industries receiving significant funding.
- Understand funding distribution across investment rounds.
- Explore investor activity and funding patterns.
- Present key insights through interactive visualizations.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Data Modeling** – Organizing data for analysis

## 📊 Dashboard Features
- **Funding Overview:** Key funding metrics and an overall summary.
- **Funding Trends:** Analysis of funding patterns over time.
- **Industry Analysis:** Comparison of funding across industries.
- **Investment Round Analysis:** Exploration of different funding rounds.
- **Investor Analysis:** Insights into investor participation and funding activity.
- **Interactive Filters:** Slicers for exploring the data.

## 📈 Key Learnings
- Developed an interactive dashboard using Power BI.
- Practiced data cleaning and transformation.
- Applied data visualization techniques to communicate insights.
- Improved skills in analytical thinking and dashboard design.
